## Install

1. Download **Marvexa-Setup.exe** using the link above.
2. Open it, choose where to install it, and finish the wizard. It adds shortcuts on the desktop and in the Start menu.
3. Open **Marvexa** and sign in with your Marvexa account.

Windows may show **"Windows protected your PC"** because the app is new. Select **More info → Run anyway**.

The **portable version** is a single file that runs without installing. It adds no shortcuts and has nothing to uninstall.

## Requirements

- Windows 10 or 11 (64-bit)
- An internet connection. Marvexa connects to [marvexa.tech](https://marvexa.tech), and your data stays there

## Uninstall

Go to **Settings → Apps → Installed apps → Marvexa → Uninstall**.
